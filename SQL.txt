Изучение SQL:

База данных — это набор данных, хранящихся в структурированном виде

Система управления базами данных — это совокупность языковых и программных средств, которая осуществляет доступ к данным, позволяет их создавать, менять и удалять, обеспечивает безопасность данных и т.д.

Рейтинг СУДБ:
    Oracle - реляционная СУБД
    MySQL - реляционная СУБД
    Microsoft SQL Server - реляционная СУБД
    PostgreSQL - реляционная СУБД
    MongoDB - документоориентированная СУБД
    Redis - хранилище по типу «ключ-значение»
    Snowflake - облачная реляционная СУБД
    Elasticsearch - поисковой движок
    IBM Db2 - реляционная СУБД
    SQLite - реляционная СУБД

Классификация баз данных:
    1)Реляционные - Данные в связанных таблицах — строки и столбцы
    2)Key-value - Быстрый доступ к значению по ключу
    3)Документоориентированные - Гибкие документы в формате JSON

Особенности реляционных БД:
    Модель данных в реляционных БД определена заранее и является строго типизированной
    Данные хранятся в таблицах, состоящих из столбцов и строк
    На пересечении каждого столбца и строчки допускается только одно значение
    Каждый столбец проименован и имеет определённый тип, которому следуют значения со всех строк в данном столбце
    Столбцы располагаются в определённом порядке, который определяется при создании таблицы
    В таблице может не быть ни одной строчки, но обязательно должен быть хотя бы один столбец
    Запросы к базе данных возвращают результат в виде таблиц

Реляционная база данных состоит из:
    Строк, которые называют <<записями>>
    Столбцов, которые называют <<полями>> или же <<атрибутами>>

В каждой таблице каждый столбец имеет заранее определённый тип данных.

Для того чтобы узнать типы данных атрибутов, можно выполнить SQL команду и указать название таблицы:
    DESCRIBE FamilyMembers

Ключевое поле (первичный ключ) – это поле (или набор полей), значение которого однозначно определяет запись в таблице.
Внешний ключ – это поле (или набор полей) в одной таблице, которое ссылается на первичный ключ в другой таблице.

Таблица с внешним ключом называется дочерней таблицей, а таблица с первичным ключом называется ссылочной или родительской таблицей.

SQL — язык структурированных запросов (SQL, Structured Query Language), который используется в качестве эффективного способа сохранения данных, поиска их частей, обновления, извлечения и удаления из базы данных.

Одна из основных функций SQL — это получение выборок данных из СУБД. Для этого в SQL используется оператор SELECT
Для вывода всех данных воспользуемся: SELECT * FROM <name>
Вывод данных из определенных колонок таблицы: SELECT <name>, <name> FROM <name>
Вывод столбцов с иным названием: SELECT <name> <name> AS <new_name> FROM <name> Или же просто не писать AS, а указать через пробел имя

Литерал — это указанное явным образом фиксированное значение, например, число 12 или строка 'SQL'.

Основными типами литералов в SQL являются:

    строковый
    числовой
    логический
    NULL
    литерал даты и времени

Числовые литералы:
    Включает в себя целые и дробные числа. Разделительный знак для дробного числа — «.» (точка)
    Может иметь только целую, дробную часть или обе сразу
    Может быть положительным и отрицательным числом (для положительного числа совсем не обязательно указывать знак)
    Могут быть представлены в экспоненциальном виде. (1e3 = 1000, 1e-3 =0.001)
Литералы даты и времени
    Значения даты и времени могут быть представлены в формате строки или числа.
    Например, если мы хотим указать какую-то дату в запросе, то мы можем это сделать с помощью строки '1970-12-30' или '19701230'.
            Описание	                                                                                Формат

    Дата	Интерпретируется как дата со временем, равным нулю	                                YYYY-MM-DD, YYYYMMDD
                                                                                                Вместо разделителя "-" можно использовать любой знак препинания.

    Время	Содержит только время без конкретной даты	                                        hh:mm:ss, hh:mm, hh, ss
                                                                                                Разделитель тоже можно опустить.

    Дата и время	Дата с возможностью задать конкретное время	                                YYYY-MM-DD hh:mm:ss, YYYYMMDDhhmmss
                                                                                                Например: '20200101183030' = 1 января 2020, 18:30:30



Логические литералы:
    Логический литерал - значения true и false, означающие истинность и ошибочность какого-либо утверждения.


NULL:
    Значение NULL означает "нет данных", "нет значения". Оно нужно, чтобы отличать пустые значения, такие как строка нулевой длины или "пробел", от ситуации, когда значение отсутствует вовсе.


Встроенная функция – реализованный в СУБД кусок кода, с помощью которого можно выполнять преобразования строковых, числовых и других данных в запросах.
    Часть функций:
        1) LOWER() - SELECT UPPER('Hello world') AS upper_string;
        2) UPPER() - SELECT LOWER('SQL Academy') AS lower_string;
        3) EXTCART(YEAR, MONTH, DAY) - SELECT EXTRACT(YEAR FROM DATE '2022-06-16') AS year;
        4) POSITION - SELECT POSITION('academy' IN 'sql-academy') AS idx;
        5) LENGTH - SELECT LENGTH('sql-academy') AS str_length;
        6) LEFT - SELECT LEFT('sql-academy', 3) AS str;
        7) RIGHT - SELECT RIGHT('sql-academy', 3)

C помощью DISTINCT можно убрать все дубликаты из вывода:
    пример:  SELECT DISTINCT class FROM STUDENT_IN_CLASS
