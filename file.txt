
Ветки в Git:

    Ветка - ссылка на коммит
    Ветки всегда ссылаются на самый последний коммит в своей ветке
    По умолчанию git создает ветку Master

    Для переключения между ветками используем: git checkout <название ветки>

    Для создания новой ветки используем: git branch <branch name>
    Для создания ветки и перехода в нее используем: git checkout -b <branch name>
    git branch - Отображает список всех веток
    git branch -m <new branch name> - Переименование текущей ветки
    git branch -d <branch name> - Удаление ветки(текущую ветку удалить нельзя)

    Слияние веток:
        После слияния веток мы получаем Merge commit - коммит, который обьединяет истории двух или более веток

        git merge <feature branch name> -  Слияние другое ветки(feature branch) в текущую ветку(receiving branch)
        git merge - m <message> <feature branch name>


Сервисы хостинга git репозиториев:
    git clone <url> - Клонирование удаленного репозитория в локальный
    origin - имя удаленного репозитория по-умолчанию

    git branch -a - Отображает все ветки, включая те, которые находятся в удаленных репозиториях
    git pull - Загрузка и применение изменений с удаленной ветки в локальную
    git push - Загрузка изменений из локальной ветки в ветке удаленного репозитория

    Связь локального репозитория с удаленным:
        git remote add origin <url> - Подключение удаленного репозитория(origin - имя)
        git push -u origin <branch> - Загрузка изменений из локальной ветки в удаленную с созданием связи между ними
